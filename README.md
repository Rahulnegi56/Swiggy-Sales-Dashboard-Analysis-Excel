# Swiggy-Sales-Dashboard-Analysis-Excel
Project Overview 
This project analyzes Swiggy sales data containing over 197K order records. The objective was to clean and transform raw data, create meaningful business metrics, and build an interactive dashboard for sales performance analysis.

Objectives to Analyze --
Total Sales
Average Rating
Average Order Value (₹)
Ratings Count
Total Orders &
Generate actionable insights using Excel reporting techniques.

Data Preparation
Cleaned and standardized raw data in Excel.
Removed inconsistencies and missing values.
Created engineered columns:
Day
Week
Quarter
Food Type

Tools Used
Microsoft Excel
Power Query
Pivot Tables
Pivot Charts
Slicers
Data Visualization

Key Insights
Generated ₹53.01M in total sales from 197K+ orders.
Average customer rating remained stable at 4.34.
Veg food contributed the majority share of revenue.
Bengaluru was the highest revenue-generating city.
Weekend sales outperformed most weekdays.
Q2 recorded the highest sales performance among all quarters.
Project Outcome

Built an interactive Excel dashboard that enables stakeholders to monitor sales performance, compare trends, and make data-driven business decisions efficiently.
